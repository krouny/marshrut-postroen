# Маршрут Построен

Веб-сервис для планирования путешествий: поиск по любому городу мира, ИИ-планировщик отдыха по дням, совместные поездки с чатом и общей папкой билетов.

**Живой сайт:** (https://markizy-trravel.netlify.app/)

---

## Что умеет

### Поиск направления
- Поиск **любого города мира** — подсказки из локальной базы популярных направлений + геокодинг OpenStreetMap для всего остального
- Категории: отели, рестораны, экскурсии, билеты, «О городе»
- Параметры поездки (даты, гости) задаются один раз и **подставляются в ссылки партнёров** — Booking, Яндекс Путешествия, Ostrovok, Ozon Travel, Aviasales открываются с готовым поиском

### «О городе»
Автоматически собираемый гид: описание из Википедии, достопримечательности рядом (геопоиск по координатам) с фотографиями, идеи чем заняться.

### Планировщик поездки
Пошаговая анкета (направление, состав, бюджет, интересы, свободные пожелания + голосовой ввод) → план по дням.

Ключевая особенность — **определение типа направления**: сервис анализирует описание места и подбирает сценарий отдыха:

| Тип | Пример | Логика плана |
|---|---|---|
| Пляж / острова | Мальдивы, Пхукет | море, снорклинг, морские прогулки, трансфер катером |
| Горы | Шерегеш, Роза Хутор | канатная дорога, треккинг, СПА после гор |
| Природа | Териберка, Байкал | рыбалка, лодка, база отдыха |
| Город | Прага, Токио | музеи, прогулки, гастрономия |

### Личный кабинет
- Сохранённые маршруты, статистика (страны, города, км, очки, уровень)
- Карта путешествий (Leaflet) с соединением точек маршрутом + ручное добавление прошлых поездок
- Рейтинг путешественников (общий, из базы)

### Совместные поездки
- Разделы: текущие / будущие / архив (статус вычисляется по датам)
- Приглашение участников по ссылке (работает и для незарегистрированных)
- Общие билеты, брони и файлы (приватное хранилище, доступ только участникам)
- **Чат в реальном времени** (Supabase Realtime)

### Прочее
- Общий чат сайта с фильтром мата/рекламы и модерацией владельцем
- Конвертер валют с автообновлением курсов
- Живая активность: кто сейчас на сайте и какие города смотрят (Realtime Presence)
- Напоминания о ближайших поездках (в интерфейсе + системные уведомления)
- Тарифы с активацией по коду

## Технологии

**Frontend:** vanilla JavaScript (ES5-совместимый), CSS custom properties, адаптивная вёрстка, светлая тема, анимированный градиентный фон.

**Backend:** [Supabase](https://supabase.com) — PostgreSQL, авторизация по email, Row Level Security, Realtime-подписки, файловое хранилище.

**Карты:** Leaflet + CartoDB tiles.

**Внешние данные:** Wikipedia REST/Action API (описания, фото, геопоиск достопримечательностей), Nominatim (геокодинг), open.er-api.com (курсы валют).

**Хостинг:** Netlify.

Проект собран как **один HTML-файл без сборщика** — сознательное решение: мгновенный деплой перетаскиванием, отсутствие зависимостей и цепочки сборки, полный контроль над размером.

## Структура

```
├── index.html   — всё приложение (разметка, стили, логика)
├── sql/         — схемы базы данных Supabase
│   ├── supabase-schema.sql        профили, маршруты, рейтинг
│   ├── supabase-trips.sql         поездки, участники, приглашения, чат
│   ├── supabase-storage.sql       приватное хранилище файлов
│   └── supabase-global-chat.sql   общий чат с модерацией
└── assets/      — варианты аватара (SVG)
```

## Запуск

```bash
# открыть локально
start index.html
```

Для работы аккаунтов, поездок и чата нужен проект Supabase: выполнить файлы из `sql/` в SQL Editor и указать свои `SUPABASE_URL` / `SUPABASE_KEY` в `index.html`.

> Ключ в коде — публичный `anon key`. Доступ к данным ограничен политиками Row Level Security на стороне базы, поэтому его размещение в клиенте безопасно и предусмотрено архитектурой Supabase.

## Архитектурные решения

- **Отказоустойчивость.** Все внешние запросы обёрнуты в таймауты; при недоступности сервиса интерфейс не зависает, а строит результат по имеющимся данным.
- **Работа без бэкенда.** Если база недоступна, сайт продолжает работать на `localStorage` — поиск и планировщик остаются доступны.
- **Честность данных.** Сервис не выдумывает цены и не показывает фиктивную статистику: цифры в кабинете считаются из реальных действий пользователя, демо-карточки помечены как примеры.
- **Безопасность.** Разграничение доступа реализовано политиками RLS на уровне базы, а не проверками в браузере.
